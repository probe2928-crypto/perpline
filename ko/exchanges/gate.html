Gate 소개

Gate는 2013년부터 운영됐고 알트코인 무기한 선물 종목이 가장 많은 편이에요. 표시된 요율은 USDT 무기한 VIP0(기본) 등급이에요.

Gate의 기본 테이커 수수료는 수수료가 확인된 9곳 중 3위예요. 40% 페이백을 받으면 실제로 내는 0.03%는 목록의 다른 모든 거래소의 기본 테이커 수수료보다 낮아요.

V · 질문

Gate 레퍼럴 FAQ

Gate 레퍼럴 코드는 뭔가요?

저희 Gate 레퍼럴은 가입 링크로 자동 적용돼서 따로 입력할 코드가 없어요. 저희 링크로 가입한 뒤 텔레그램 @btcbullit에게 UID를 보내면 40% 수수료 페이백이 활성화돼요.

Gate에서는 페이백을 얼마나 받나요?

Perpline은 Gate에서 낸 선물 거래 수수료의 40%를 매주 USDT로 돌려드려요. 일반 테이커 수수료 0.05% 기준으로 실제 요율은 0.03%가 돼요.

Gate 선물 수수료는 얼마인가요?

Gate의 일반(비 VIP) USDT 무기한 선물 수수료는 메이커 0.02%, 테이커 0.05%예요 (2026년 10월 확인). 실제로는 계정에 적용된 요율이 우선해요.

기존 Gate 계정에 레퍼럴 코드를 추가할 수 있나요?

보통은 안 돼요. 거래소는 계정을 만들 때 레퍼럴을 연결하므로, 페이백을 받으려면 저희 링크로 새 Gate 계정을 만들어야 해요.

비밀번호나 API 키가 필요한가요?

아니요. 거래소 이름과 계정 UID만 있으면 돼요. 비밀번호, 2FA 코드, API 키는 누구에게도 알려주지 마세요.

제 국가에서도 Gate 이용이 가능한가요?

서비스 국가는 Gate에서 정해요. 가입 전에 거주 국가 관련 약관을 확인하세요. 이 사이트는 대한민국과 미국 거주자를 대상으로 하지 않아요.
